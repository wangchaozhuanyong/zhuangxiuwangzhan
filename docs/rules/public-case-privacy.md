# 公开案例隐私与地点写入规则

适用于前台落地页、案例卡片、SEO 文案、图片说明和后台 CMS 录入。

## 地点颗粒度

- 可以公开：`吉隆坡`、`雪兰莪`、`巴生谷`、`马来西亚`及对应英文名称。
- 商业案例卡片不公开街道、门牌、楼宇、商场、园区、交通枢纽、住宅项目、镇区或其他可定位具体客户的地点。
- 表单中的准确项目地点只用于内部评估，不能自动复制到公开案例。

## 客户与项目名称

- 不公开客户、公司、品牌、门店、餐厅、诊所、商场档口或物业项目的真实名称。
- 未取得书面授权时，不以 Logo、招牌、门牌、工牌等可识别信息作为公开图片重点。
- 案例标题只描述空间类型和改造重点，例如“办公空间布局规划参考”。

## 案例真实性

- 无法确认是已完工实拍时，使用“项目参考”“规划参考”或“设计方向”，不得包装成真实完工客户案例。
- 不虚构客户身份、公司规模、项目地址、预算、工期、面积或评价。
- 图片只说明空间类型或规划方向时，页面必须显示隐私与用途说明。

## 办公室落地页强制规则

- `office-renovation` 的案例卡片在前台自动匿名化。
- 后台发布只接受批准的匿名标题，以及吉隆坡、雪兰莪、巴生谷等大区域。
- 不符合规则的已发布内容会被后台阻止保存。
- 即使内容绕过后台直接写入数据库，前台仍会替换标题和地点。

## 发布前检查

1. 搜索公司名、品牌名、门店名、楼宇名、街道名和小区域名。
2. 检查图片中是否出现 Logo、招牌、门牌或人员信息。
3. 确认标题描述空间和工作内容，不描述客户身份。
4. 确认地点保持在城市或州级别。
5. 没有真实依据时，不使用“完工案例”“客户实拍”等表述。
