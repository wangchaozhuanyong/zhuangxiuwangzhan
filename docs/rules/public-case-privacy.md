# 公开案例隐私与地点写入规则

适用于前台落地页、案例卡片、SEO 文案、图片说明和后台 CMS 录入。

## 地点颗粒度

- 可以公开：`吉隆坡`、`雪兰莪`、`巴生谷`、`马来西亚`及对应英文名称。
- 商业案例卡片不公开街道、门牌、楼宇、商场、园区、交通枢纽、住宅项目、镇区或其他可定位具体客户的地点。
- 表单中的准确项目地点只用于内部评估，不能自动复制到公开案例。

## 客户与项目名称

- 不公开客户、公司、品牌、门店、餐厅、诊所、商场档口或物业项目的真实名称。
- 未取得书面授权时，不以 Logo、招牌、门牌、工牌等可识别信息作为公开图片重点。
- 案例标题只描述空间类型和改造重点，例如“办公空间布局规划参考”。

## 案例真实性

- 效果图使用“设计效果图”；其他规划内容使用“项目参考”“规划参考”或“设计方向”，不得包装成真实完工客户案例。
- 不虚构客户身份、公司规模、项目地址、预算、工期、面积或评价。
- 图片只说明空间类型或规划方向时，使用准确、简洁的用途标签；客户隐私按前述规则处理，效果图按下节标注。

## 效果图对外标注

- 中文使用“设计效果图”，英文使用“Design rendering”。材质图使用“材质搭配示意” / “Material palette study”，布局图使用“布局示意” / “Layout study”。
- 首屏、卡片、图片角标、正文、弹窗、alt 和 SEO 文案保持一致，不自动追加“人工智能概念图”“非完工案例”“非客户完工实景”“不代表已完工项目”等生成方式或否定式说明；英文规则相同。
- 图片说明直接描述空间、布局、光线和材质，不重复堆叠用途声明。用户当次明确要求展示某项说明时按该要求执行。
- “设计效果图”是图片类型标注，不能替换为“实景”“已交付项目”“客户实拍”，不能附加未经核实的案例事实。
- 图片生成来源、授权与可用范围保留在内部素材记录、审计或交付资料，不因简化公开措辞而删除。
- 改动须同步中英文及关联的共享媒体标签，并检查页面、弹窗和辅助文本中的残留文案。

## 办公室落地页强制规则

- `office-renovation` 的案例卡片在前台自动匿名化。
- 后台发布只接受批准的匿名标题，以及吉隆坡、雪兰莪、巴生谷等大区域。
- 不符合规则的已发布内容会被后台阻止保存。
- 即使内容绕过后台直接写入数据库，前台仍会替换标题和地点。

## 发布前检查

1. 搜索公司名、品牌名、门店名、楼宇名、街道名和小区域名。
2. 检查图片中是否出现 Logo、招牌、门牌或人员信息。
3. 确认标题描述空间和工作内容，不描述客户身份。
4. 确认地点保持在城市或州级别。
5. 没有真实依据时，不使用“完工案例”“客户实拍”等表述。
