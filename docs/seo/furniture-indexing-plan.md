# 家具产品页：收录策略（修正版）

> 日期：2026-11-21（修正）
> 更正：本文件初版建议「产品页 noindex」。**该结论已被推翻**，原因见第一节。
> 对象：`/en|zh/furniture/product/*` 共 616 个页面

---

## 一、初版为什么错了

初版用 `curl` 抓初始 HTML，得到 167–540 字符、无价格，据此判定「全是空壳」。

**初始 HTML 不等于用户看到的页面。** 用真实浏览器渲染后：

| 产品 | 爬虫看到的初始 HTML | 用户看到 | 页面上有价格 |
|---|---|---|---|
| `ws-2102-wooden-bunk-bed-white` | 368 字符 | 1,006 字符 | RM1,900.00 |
| `cloudy-3-seater-easy-clean-sofa-beige` | 457 | 590 | RM1,900.00 |
| `dophin-queen-size-bedframe-blue` | 418 | 536 | RM1,872.00 |
| `bb-606-heavy-duty-full-solid-bunk-bed` | 454 | — | 有 |

**价格是显示的，内容是存在的。** 「noindex」这个判断建立在错误前提上。

## 三、真正的问题

**产品页缺 SEO 预注入。**

和区域页、FAQ 修好之前完全同一个病：内容只在客户端渲染，爬虫的初始 HTML 里没有。

用户能看见价格，Google 看不见。

---

## 四、修正后的方案

### 保留收录，加预注入

| 项 | 做法 |
|---|---|
| 收录 | **保留**，不 noindex |
| 预注入 | 商品名、SKU、价格（或 Price on request）、规格、尺寸、图片 alt、所属分类链接、相关产品链接 |
| 描述扩写 | **不需要**。150 个产品已有价格和规格，预注入后爬虫可见内容从 368 → 1,000+ |
| URL | 建议改，但不阻塞 |

### 预期效果

| 指标 | 现在 | 改完 |
|---|---|---|
| 产品页爬虫可见 | 368–457 字符 | 1,000+ 字符 |
| 薄页面（<800 字符） | 825 | 约 200 |
| sitemap | 1,379 | 1,379（不变，不删页面） |

**注意：sitemap 数量不变。** 这次不是删页面，是让已有页面变得可读。

## 五、URL 问题（独立于预注入）

数据里 308 个产品**本来就有英文 slug**：

```
slug 字段：ws-2102-wooden-bunk-bed-white
实际 URL：/en/furniture/product/%E4%BA%91%E5%9B%A2%E6%B2%99%E5%8F%91
```

页面路由用的是中文拼音，而不是数据里现成的英文 slug。

**所以要做的不是重新起名，是把已有英文 slug 用起来 + 301 重定向。**

好处：搜索结果里显示 `.../cloudy-3-seater-sofa-beige` 而不是一串 `%E4%BA%91...`，点击率差别明显。

代价：616 个 301 重定向，需要保留旧 URL 可访问。

**建议排在预注入之后，不急。**

---

## 六、158 个没价格的产品

约一半产品显示「Ask for price」（预售/询价）。这是合理的商业做法，不是缺陷。

如果要做，补一个「起价」或「参考区间」即可，不必给准确价。

---

## 七、结论

**家具是主营，产品页有价值（有图、有规格、一半有价格）。**

问题不在内容，在**爬虫可见性**。修预注入，不删页面。
