# 本地引用建设手册（Local Citations）

> 目标：让 Google 在多个可信来源上看到同一套 NAP（名称 / 地址 / 电话），这是本地包排名里「知名度」那一项的实体信号。
> 原则：**一致性 > 数量**。10 个完全一致的引用，胜过 50 个写法各异的。

---

### 五种常见写法错误（必查）

| 错误写法 | 为什么有害 |
|---|---|
| `FLASH CAST Renovation` / `Flashcast装修` | Google 禁止在名称里堆关键词，会被降权 |
| `011-2885 3888` / `+601128853888` / `01128853888` | 三种格式只能留一种，混用会打断实体匹配 |
| 地址写成 `Taman United, Off Jalan Klang Lama` | 变体可以出现在描述里，不能出现在地址字段 |
| 邮编写成 `58200 KL` | 必须是 `58200`，城市单独一栏 |
| 网址带 `www.` 或不带 `https://` | 统一用 `https://flashcast.com.my` |

## 5. 明确不要做的

| 不要做 | 原因 |
|---|---|
| 买目录套餐（几十个站打包提交） | 大多是低质量站群，反而拖累信任度 |
| 在 Fiverr 类平台买「本地引用服务」 | 同上，且 NAP 常被写错 |
| 提交到与业务无关的目录 | 相关性低，Google 会忽略甚至视为操纵 |
| 同一地址注册多个商家名 | 会被判定为重复实体 |
| 用虚拟办公室地址 | 一旦被核实，GBP 会被暂停 |

## 9. 一个务实的判断

引用建设对本地包的作用是「加速」而不是「决定」。真正决定本地包排名的是类目、距离和评价数。

**所以优先级应该是**：

```
1. 评价（已有 2 条 5.0 星 → 目标 10 条）  ← 影响最大
2. 类目与服务项（已完成）
3. 引用一致性（本手册）
4. 照片（影响点击率，不影响排名）
5. 外部链接（长期）
```

**如果你时间有限，先做评价，再做引用。** 本手册是第二梯队的工作，不要因为做它而推迟索评。

### 待办：更新 CIDB 联络电话

**CIDB 档案里的电话 `01-23381417` 与对外使用的 `011-2885 3888` 不同。**

风险：客户在 CIDB 查到注册信息后，若拨打档案里的号码而该号已停用，这条线索直接丢失——而客户此刻的信任度是最高的。

**做法**：登录 CIMS 系统更新联络号码。这是注册信息维护，不是新注册。

### 结论：这是引用，不是外链

CIDB 档案可以公开打开，但页面**不提供指向 flashcast.com.my 的可点击链接**。

所以：

- ✅ 计入「政府名录引用」——一条可信的 NAP 核对来源
- ❌ 不计入外链数

这与本手册第 0 节的原则一致：引用的价值是一致性，不是权重传递。**但前提是信息一致**，所以上面的电话必须先修好，否则这条引用反而是干扰项。
