## 12. 优化规则

### 12.1 加否定词

搜索结果里出现以下类型，当天加否定词：

```
DIY 教程、维修、招聘、课程、批发、二手、其他品牌型号
```

### 12.2 调价

| 情况 | 动作 |
|---|---|
| 有转化且 CPC 低于建议价 | 提价 10%，争取更多曝光 |
| 无转化但 CTR 高 | 检查落地页，不要急着降价 |
| 无转化且 CTR 低 | 降价 20% 或暂停 |
| 完全没曝光 | 检查出价是否低于首页最低价，提价 |

### 12.3 暂停

关键词累计 50 次点击无转化 → 暂停。

广告组累计 RM300 花费无转化 → 暂停，检查落地页。

### 12.4 换智能出价

累计 15 条转化后，切换为「尽可能争取更多转化」，目标 CPA 设为实际单条线索成本的 1.2 倍。

## 13. 禁止事项

| 禁止 | 原因 |
|---|---|
| 广告文案出现竞对商标 | 商标投诉，广告拒登 |
| 落地页与广告内容不一致 | 质量得分归零，CPC 翻倍 |
| 承诺未经验证的工期（如「当天上门」） | 误导性内容，账号受限 |
| 虚假原价、假倒计时 | 账号受限 |
| 自己点击广告 | 账号永久封停，支付方式关联封禁 |
| 使用多个账号绕开限制 | 关联识别，全部封停 |
| 修改价格数字 | 与落地页不一致，会被判误导 |

## 15. 三语投放的关键差异

| 语言 | 客户真正在意的 | 文案重点 |
|---|---|---|
| 英文 | 价格含不含安装、装前会不会乱开孔 | Installation included、door checked before drilling |
| 马来语 | 有没有上门、价格透不透明 | Harga termasuk pasang、pasang di kawasan anda |
| 中文 | 会不会被区别报价、装坏了谁负责 | 含安装价、装前核对门型、开孔先确认 |

**三者共同点**：语言不是决定因素，响应速度才是。

广告点击进来的客户发 WhatsApp 问价，10 分钟内有人回，语言是什么都不重要；两小时不回，说什么都没用。广告时段锁定 10:00–19:00，就要保证这段时间 WhatsApp 有人盯。
