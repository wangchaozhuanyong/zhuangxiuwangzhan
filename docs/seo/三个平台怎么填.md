# 一、发 Google 帖子（3 分钟）

## 1. 打开网址

```
business.google.com/posts
```

## 2. 确认账号

右上角圆形头像 → 点一下，确认是管 Google 地图那个账号。

## 3. 点「添加帖子」

页面上的蓝色按钮，写着「添加帖子」或「Add post」。

## 4. 粘贴这段

```
Q: Are you a registered contractor?

A: Yes. FLASH CAST is a registered Malaysian company and a CIDB registered contractor, graded G3. We provide itemised quotations that separate confirmed work, exclusions and owner-supplied items, so you know what is included before work starts. Message us if you would like to see our registration certificate.
```

## 5. 加照片

输入框下方点相框图标 → 选：

```
E:\源码文件夹\装修网站\docs\seo\gbp-photos-20261121\上传这5张\3-完工客厅.jpg
```

## 6. 加按钮

点「添加按钮」→ 选「了解更多」→ 网址填：

```
https://flashcast.com.my/zh/about
```

## 7. 发布

右下角点「发布」。

# 二、Bing Places（15 分钟）

## 1. 打开

```
bingplaces.com
```

## 2. 登录

右上角「Sign in」→ 用**微软账号**（Outlook / Hotmail / Windows 开机账号）。

没有就点「Create one」用常用邮箱注册。

## 3. 选「从 Google 导入」

看到两个选项时，选：

```
Import from Google Business Profile
```

## 4. 授权

跳到 Google 页面问是否允许 → 点「允许」。

## 5. ⚠️ 检查两处（自动填的经常错）

**① 电话**

如果变成 `(60) 11-2885 3888` 或 `601128853888`，改成：

```
+60 11-2885 3888
```

**② 类目**

改成 `Renovation Contractor`（下拉框搜 "Renovation"）。

## 6. 营业时间

```
每天 10:00 - 19:00
```

## 7. 提交 + 接电话

点 Save / Submit → 选**电话验证** → 手机会响，听 4 位数字，输进网页。

# 三、苹果地图（20 分钟）

## 1. 打开

```
businessconnect.apple.com
```

## 2. 登录

「Sign in」→ 用 **Apple ID**（iPhone 那个账号）。手机会收到验证码。

## 3. 先搜公司名

点「Add Your Business」→ 搜 `FLASH CAST`

- 搜得到 → 点进去选「Claim this business」
- 搜不到 → 点「Add a new business」

## 4. 填资料（照抄，别改）

| 项目 | 填什么 |
|---|---|
| 公司名 | `FLASH CAST` |
| 街道 Street | `94, Jalan Mega Mendung, Taman United` |
| 城市 City | `Kuala Lumpur` |
| 邮编 Postal Code | `58200` |
| 国家 Country | `Malaysia` |
| 电话 | `+60 11-2885 3888` |
| 网站 | `https://flashcast.com.my` |
| 邮箱 | `support@flashcast.com.my` |
| 类目 | `Contractor` 或 `Home Improvement` |
| 营业时间 | 每天 10:00 到 19:00 |

## 5. 上门面照

上传：

```
...\上传这5张\1-门面.jpg
```

## 6. 提交

点 Submit。苹果要人工审核，**3–5 天**，结果发邮件。

# 四、Waze（5 分钟，必须在店门口）

Waze 要求手机 GPS 定位在现场，远程做不了。

## 步骤

```
1. 手机打开 Waze App
2. 站在店门口，等蓝点定位到你
3. 长按地图上店的位置（按住 2 秒）
4. 点「Add a place」
5. 填：
   名称  FLASH CAST
   类目  Contractor
   地址  94, Jalan Mega Mendung, Taman United, 58200 Kuala Lumpur
   电话  +60 11-2885 3888
6. 现场拍一张门面照上传
7. 提交
```
