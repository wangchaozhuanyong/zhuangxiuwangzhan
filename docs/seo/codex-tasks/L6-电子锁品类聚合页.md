## 1. 项目背景

`locks.flashcast.com.my` 现在有 3 个首页 + 51 个型号页（`/{lang}/lock/{slug}/`），由 `functions/anzheShowroom.ts` 的 `pagePath` 正则放行，静态文件在 `public/anzhe-showroom/{lang}/lock/`。

`catalog.js` 里每个型号已有 `group` 字段（`entrance` 14 款 / `room` 2 款 / `slim` 1 款），`features.js` 里有功能标签。首页的筛选按钮（全部 17 / 入户门 14 / 室内门 2 / 窄框铝门 1）就是按 `group` 筛的。

**问题**：这个筛选是纯前端交互，没有独立 URL。搜索 `digital lock for aluminium door`、`face recognition door lock malaysia` 这类「属性 + 品类」词时，站点没有可匹配的落地页。

## 5. 硬性实现要求

### 5.1 中间件正则

在现有基础上扩展，**仍然不许通配**：

```ts
const LOCK_SLUGS = "v37j-p16|p59j-pro|k16j-k19|q58j-k19|k19j|q8j|r10j-22|k26j-pro|t06j|a88-face-id|gp08|f8|g53-pro|g86f-pro|g5|g13|d10b";
const TYPE_SLUGS = "entrance-door|interior-door|aluminium-door";
const FEATURE_SLUGS = "face-recognition|palm-vein|video-intercom";
const pagePath = new RegExp(
  `^/(zh|en|ms)(?:/(?:lock/(?:(?:${LOCK_SLUGS})|(?:(?:type|feature)/(?:${TYPE_SLUGS}|${FEATURE_SLUGS})))))?(?:/(?:index\\.html)?)?$`
);
```

要点：

- `canonicalPath` 计算要覆盖两段式路径，`/zh/lock/type/entrance-door` 必须 301 到带尾斜杠版本
- 非法组合（如 `/zh/lock/type/wooden-door/`）必须 **404**
- 缓存 key 必须含完整路径，不能与型号页共用

### 5.2 页面生成

扩展 `scripts/generate-anzhe-lock-pages.mjs`，复用现有模板与样式，从 `catalog.js` 派生型号清单：

| 品类 | 型号来源 |
|---|---|
| `type/entrance-door` | `group === "entrance"` 的 14 款 |
| `type/interior-door` | `group === "room"` 的 2 款 |
| `type/aluminium-door` | `group === "slim"` 的 1 款（D10B） |
| `feature/face-recognition` | `access` 含「人脸」的款 |
| `feature/palm-vein` | `access` 含「掌静脉」的款 |
| `feature/video-intercom` | `screen !== null` 且描述含对讲/门铃的款 |

**不许手写型号清单**，必须从 `catalog.js` 派生，避免以后新增型号时品类页与目录不一致。

### 5.3 页面结构（每页）

1. `<title>` / `<meta description>` / canonical / 三语 hreflang
2. 唯一 `<h1>`
3. 40–60 字直接答案段
4. **型号列表**：每款一张卡，链到 `/ {lang}/lock/{slug}/`，显示型号名 + 一句卖点 + 含安装价
5. 该品类的选择要点（3–5 条，写成 H2 + 段落，不许只列 bullet）
6. 3 条 FAQ
7. JSON-LD：`CollectionPage` + `ItemList`（每款一个 `ListItem`）+ `BreadcrumbList` + `FAQPage`
8. 返回首页与相关品类页的链接
9. WhatsApp CTA

## 9. 边界与失败处理

| 情况 | 处理 |
|---|---|
| 某个品类只有 1 款（铝门） | 正常，不要为了凑数把其他款塞进去 |
| 功能分类在 `access` 里匹配不到 | 输出诊断，不要自己猜，也不要改 catalog.js |
| 首页筛选按钮改动导致现有交互坏掉 | 回滚交互改动，只保留新增链接 |
| 品类页与型号页正文重复度过高 | 品类页正文必须是「选择要点」，不是型号页内容搬运 |
| 与 L5 的分支冲突 | 说明冲突文件，等 main 更新后 rebase，不要强推 |
