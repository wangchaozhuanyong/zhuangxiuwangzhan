| `renovation` | 原 EN 48 字符但缺 Selangor；描述 208 字符过长会被截断 |

| `bathroom` | 原 EN 45 字符偏短且缺 waterproofing 这个词根 |
| `office-renovation` | 原 EN 44 字符，缺 fit-out 关键词 |
| `shop-renovation` | 原 ZH 标题 31 字超过 30 上限；补 shoplot 词 |
| `artistic-coating` | 原 SEO 字段全部为空，等于该页没有标题和描述 |
| `old-house` | 原 EN 46 字符偏短；描述 204 字符过长 |
| `warehouse` | 原 EN 68 字符严重超长，且没有 FLASH CAST 品牌后缀；ZH 41 字超上限 |
| `approval` | 原 SEO 字段全部为空；该页是建立信任的关键页 |
