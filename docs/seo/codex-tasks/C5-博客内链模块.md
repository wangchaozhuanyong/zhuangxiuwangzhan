# Codex 任务 C5：博客底部「相关落地页」内链模块

> 投放方式：整篇粘给 Codex。
> 前置：C1 或 C2 至少完成一个（要有可链的目标页），并拿到内容侧的锚文本映射表。

---

## 1. 项目背景（自包含）

仓库 `flashcast-website`，三语（`en` / `zh` / `ms`），博客路由 `/:lang/blog/:slug`。

博客数据两层来源（CMS 优先，同服务页）：

- 静态：`src/data/blog.ts`（12 条 `BlogPost`）
- CMS：Supabase `blog_posts` 表，经 `usePublishedBlogPosts` / `usePublishedBlogPostBySlug`

线上实际文章数约 38 篇，多数在 CMS。

**现状痛点**：博客是纯信息流，正文结尾没有通往「服务 / 落地页」的出口，读完就走，不转化。

## 2. 本次目标

在每篇博客正文下方，加一个「相关服务」模块，按映射关系链到 1–2 个落地页或服务页。

要求：
- 映射关系**数据驱动**，不写死在组件里
- 锚文本从配置读取，每篇不完全相同
- 样式像正文延伸，不像广告位

## 4. 允许修改 / 禁止修改

**允许**：
- `src/components/blog/`（新建 `RelatedServiceLinks.tsx` 或类似）
- `src/pages/BlogDetail.tsx`（挂载模块）
- 新建映射配置文件，如 `src/data/blogServiceLinks.ts`
- `src/i18n/` 下新建模块标题文案（三语）

**禁止**：
- 不要改 `src/data/blog.ts` 里文章的正文内容
- 不要用脚本直接改 `blog_posts` 表（绕过后台发布链路）
- 不要在映射里硬编码 `/en/...` 这种带语言前缀的绝对路径（要用 `withLanguagePrefix` 之类的现成工具）

## 5. 硬性要求

1. **数据结构**：

```ts
type BlogServiceLink = {
  target: string;      // 目标路径，不带语言前缀，如 "/services/kitchen"
  anchor: { en: string; zh: string; ms: string };
};

export const blogServiceLinks: Record<string /* blog slug */, BlogServiceLink[]> = { ... };
```

2. **覆盖要求**：映射表要覆盖**当前线上全部博客 slug**，不是只覆盖 `src/data/blog.ts` 的 12 篇。请先从 CMS 读出实际 slug 列表（或从 `dist` 产物 / sitemap 里提取），在报告里列出清单。**如果拿不到 CMS 数据，就输出「需要业主提供的 slug 清单模板」，不要凭猜写映射。**

3. **兜底策略**：没有映射的博客，模块**不渲染**（不要显示空盒子或默认链到首页）。这是硬要求——空模块比没模块更伤体验。

4. **锚文本规则**：
   - 同一锚文本在站内出现不超过 3 次
   - 锚文本必须是描述目标页内容的短语，禁止 `click here`、`read more`、`learn more`
   - 三语各自自然，不要直译（例：EN `kitchen renovation in Kuala Lumpur`、ZH `吉隆坡厨房装修`、MS `pengubahsuaian dapur Kuala Lumpur`）

5. **渲染要求**：
   - 位置：正文结束、评论区/分享按钮之前
   - 结构：模块标题（三语可配）+ 1–2 个链接卡片
   - 卡片含：目标页标题（从映射配置读，不要现查数据库）+ 一句说明 + 链接
   - 移动端单列，桌面端可两列
   - 不加 `target="_blank"`（站内链接不应新开窗口）

6. **可访问性**：
   - 链接有可见的 `:focus` 状态
   - 模块用 `<nav aria-label="...">` 或 `<aside>` 语义标签
   - 对比度满足现有色彩规范（参考 `scripts/` 里的对比度检查逻辑）

7. **不追踪不到**：链接点击如果已有全局埋点就复用，不要自己造埋点系统。

## 6. 验收标准

- [ ] 映射表覆盖报告里列出的全部博客 slug
- [ ] 抽 5 篇不同博客，渲染出的锚文本各不相同
- [ ] 无映射的博客不渲染该模块（有证据）
- [ ] 三语切换后模块标题与锚文本都正确切换
- [ ] 站内链接不带 `target="_blank"`、不带硬编码语言前缀
- [ ] 移动端单列、无横向溢出
- [ ] 键盘 Tab 可聚焦，`focus` 可见

## 9. 边界处理

| 情况 | 处理 |
|---|---|
| CMS 里有博客 slug 但站上没有对应页面 | 报告为死配置，映射里不要写 |
| 内容侧只给了部分映射 | 先上线已给的，其余留空（不渲染），报告列出待补 |
| 博客正文本身已在 CMS 里带了内链 | 不要删正文里的链接，模块是补充不是替代，报告里说明重复情况 |
| 发现博客数量与预期的 38 篇不符 | 输出实际数量与来源（CMS / 静态），不要按 38 硬凑 |
