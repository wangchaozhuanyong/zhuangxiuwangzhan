## 四、代码阶段已知遗留项说明

1. **首页 LCP 表现（4.11 秒）**：
   - 原因：首页在 Slow 4G + 4 倍 CPU 节流的严苛实验室环境下，最大绘制元素为简介段落文本。首字节时间（TTFB）为 720ms，元素渲染等待时间为 3393ms，Total Blocking Time 为 2349ms。
   - 评估：已通过轻量卡片图将首页图片下载压力降低（从 35 降至 20），真实网络（4G/5G/宽带）下的首屏加载体验显著优于实验室慢速节流结果。后续如需进一步优化，需重构首页交互目录的 JavaScript 挂载机制。
2. **Tab 顺序中的 CTA 咨询按钮**：
   - 型号页与品类页的首屏 CTA 在视觉布局上排在型号列表卡片之前，键盘 Tab 顺序忠实还原了视觉顺序，符合现有布局预期。
