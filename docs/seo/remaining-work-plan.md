## 二、P0：影响索引与收录（必须先做）

### 2.1 马来语内容：最大缺口

**现状：所有 `/ms/` 页面都是 `noindex`。** 马来语流量目前为零。

| 缺什么 | 数量 | 字段 |
|---|---|---|
| 区域页 ms 正文 | 30 个 | `content_ms` |
| 新服务页 ms 字段 | 7 个 × 10 字段 | title / seo_title / seo_description / content / excerpt / scope_items / process_steps / faqs / suitable_for / common_projects |
| 新交叉页 ms 文案 | 7 个组合 | 全套 |
| FAQ ms | 25 条 | question_ms / answer_ms |
| 首页与核心页 ms | 已有 5 个交叉页有 ms | 其余待补 |

**为什么排第一**：这是唯一一个「做好了能直接打开一个新流量池」的动作。中文和英文已经饱和，马来语是空白。

**依赖**：需要马来语母语译者。我写初稿的质量不足以直接上线——马来语客户一眼能看出是不是母语写的。

**门槛**：`hasCompleteMalayContent` 要求 ms 的 title、seo_title、seo_description 齐全，且英文有值的字段 ms 也要有。少一个字段就不进 sitemap。

## 四、P2：技术收尾

### 4.1 FAQ 页面还没有预注入

现状：`/en/faq` 初始 HTML 只有 314 字符，25 条问答全靠客户端渲染。

FAQPage schema 里有 32 条（爬虫能读），但**正文不在初始 HTML**。和区域页修复前是同一类问题。

修法：在 `functions/_middleware.ts` 里给 `/faq` 路由加载 FAQ 数据并调用 `buildReadableHomeFaqBody`。

### 4.2 privacy / terms 应移出 sitemap

4 个页面，142–148 字符，对 SEO 无价值，占用索引额度。

修法：在 sitemap 生成里加排除列表（不能改 qualification，那会触发全局校验报错）。

### 4.3 description 优化

| 问题 | 数量 |
|---|---|
| 超过 160 字符 | 543 |
| 短于 50 字符 | 165 |

优先级低于 title，但超长的那批同样会在搜索结果里被截断。

### 5.2 成本类深度文

现有：[klang-valley-renovation-cost-2026](https://flashcast.com.my/en/blog/klang-valley-renovation-cost-2026)、[malaysia-renovation-budget-guide](https://flashcast.com.my/en/blog/malaysia-renovation-budget-guide)。

```
厨房装修多少钱（马来西亚）

公寓装修预算
有地住宅装修费用
```

**依赖真实报价数据**。我不能编价格——编了就是误导客户，而且会被 Google 判低质。
