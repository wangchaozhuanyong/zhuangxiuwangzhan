# 中文 / English / Bahasa Melayu

本次范围：前台全站三语、底部语言抽屉、后台马来语编辑和补译、增量数据库字段，以及三语路由和搜索元数据。用户已明确同意增加马来语字段并保留现有内容。

## 已实现的行为

- 中文 `/zh`、英文 `/en`、马来语 `/ms`。马来语页面使用 `ms-MY`，按钮显示 `BM`，选项完整显示 `Bahasa Melayu`。
- 页头和页尾复用同一个底部抽屉。切换保留当前页面、查询参数和锚点，记住选择；支持键盘焦点、Escape、关闭按钮、背景遮罩、减少动画和手机安全区。
- 公共界面资源、表单、导航、服务、案例、材料、文章、服务区域、公司和 CMS 内容读取支持马来语。
- 内容字段先取 `_ms`，空白时暂用原有 `_en`。原有中英文不被覆盖，也不会把回退英文写入马来语字段。未完成翻译的动态页面保守地禁止索引；完整译文才进入马来语 sitemap / hreflang。
- 后台提供马来语编辑区；保存仍走原来的编辑、版本校验和发布入口。自动翻译通过现有 `generate-english-content` 增加可选参数 `targetLanguage: "ms"`，默认只补缺失字段。
- 原有权限、受保护内容发布条件、审计和并发版本校验保留。后台操作界面仍为中文和英文。
- 关联家具商城是另一个项目。马来语访客进入商城时沿用其现有英文入口。

## 上线顺序

用户已明确授权本次提交、合并 main、正式部署及线上验收。执行记录保存在项目内 `reports/malay-release-20261018/`，实际发布状态以该目录的提交、迁移、部署和线上验收证据为准。

1. 在与生产字段一致的隔离测试数据库应用 `supabase/migrations/202610180001_malay_content_fields.sql`，验证新增字段、原子材料写入和图库替换函数。生产应用时在同一事务比较原有内容指纹，保留非敏感结构及迁移回执。
2. 验证原有中英文、记录数量、状态、ID、版本、权限及审计不变。迁移只添加可空翻译列和任务目标语言，扩展既有写入白名单，不清空旧内容。
3. 必须先有数据库字段：新版公共查询会请求 `_ms` 列，顺序错误会影响原有语言的数据读取。合并后通过现有流程发布前端、中间件及翻译函数；内容保存函数遵守 `supabase-content-publish-r3.yml` 的生产审批与同版本网站前置检查。
4. 在后台补齐并校对实际 CMS 马来语正文、SEO、图片说明和结构化列表。受保护记录继续走其原审批流程。
5. 使用完整数据库快照重新生成 SEO manifest、sitemap 和 llms，再验收三种语言的实际保存、公开页面、HTML 元数据及预览性能。
6. 核对 main、构建、线上版本和函数源码的提交归属，再使用只读及不提交表单的浏览器操作进行生产验收。

## 风险和回退

- 本地静态马来语初稿包含机器翻译，已经修正部分界面和室内设计用语，仍需要熟悉马来语及装修业务的人校对，尤其是价格、施工、法律条款和长正文。
- 自动翻译沿用项目的 Google 网页翻译方式，可能遇到限流或响应变化。服务失败会报错；已有译文默认保留。占位符、HTML 标签、链接和品牌内容受到保护。
- `translationComplete` 是内容/元数据存在性检查，不等同于人工语言质量验收。
- 本地完整测试 2751 项通过，类型、严格核心类型、架构、语言完整性、交互检查通过；开发构建首屏 JavaScript 178.9 KiB，低于既有预算。手机及桌面抽屉、键盘、页面参数、语言记忆和表单草稿已通过浏览器验证。生产步骤单独记录，不以本地结果代替。
- 回退时先还原前端和函数到发布前版本；保留新增马来语列和内容，不删除数据。需要回退数据库函数时使用上线前定义，不能直接删除列或迁移文件。
- 保留原工作区已有未提交改动。发布工作在从最新 main 创建的项目内部独立工作树进行，只提交本任务相关文件。
